### 🕵️‍♂️ Geeky Cyber & Hacking Fun Facts
* **The First Computer Password:** Created in 1961 at MIT for the CTSS system, but it allowed multiple users to log into the same file simultaneously, leading to the very first password security issues!
* **Why "Phishing"?:** The term originated in the mid-1990s by hackers stealing AOL accounts using fake links. They used "fishing" as a metaphor for putting out hooks and waiting for victims to bite, changing the 'f' to 'ph' as a nod to "phreaking" (phone hacking).
* **The First Malware:** The very first computer virus, *Creeper*, was created in 1971 as an experimental self-replicating program on ARPANET. It didn't steal data; it just displayed the message: *"I'm the creeper, catch me if you can!"*
